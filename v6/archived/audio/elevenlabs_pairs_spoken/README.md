# Takes for the retired 20-item dataset

Rendered from `out/pairs_spoken.json`, which the three-stage transcript pipeline replaced.

Kept only because they cost money and are the record of the ElevenLabs stage working. **They
share item ids with the current dataset and are not its audio** — `v6_01a` here is a different
conversation from `v6_01a` in `out/transcripts.json`, which is why they had to be moved out of
the way rather than left for `make_audio.py` to find and reuse.
