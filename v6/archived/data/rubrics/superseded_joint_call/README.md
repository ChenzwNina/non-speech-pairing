# Superseded: rubrics written three-at-once

These were written by one call per item that saw all three versions together and returned three
rubrics, with a `contrastive_requirement` / `contrastive_cue` field naming what set each
condition apart from the other two.

That design guaranteed the contrast and thereby destroyed it as evidence. A writer looking at a
laugh *and* a sigh can always phrase two requirements that differ, whether or not the
conversation supports the difference — so the contrast measured how the annotation was
collected rather than anything about the stimulus.

They are kept because the flags they raised are still worth reading: nine of twenty items drew
an ambiguity flag or a review note, `scream` accounting for most of it. **They do not validate
against the current schema and are not input to anything.** The live rubrics are one per
(item, condition), written from that condition alone.
