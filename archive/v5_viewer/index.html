How the dataset is built

Each item is a minimal two-turn interaction: Speaker A says one line, Speaker B answers with only a non-speech sound — no words. Two versions share the identical Turn 1; only B's vocalization differs between them. Each version also carries a gold interpretation (what B's reaction means here) and a gold verbal continuation (what B would plausibly say next), written but never spoken.

There are no random distractors. The matching questions below are a straight forced choice between the pair's own two gold answers — nothing else to eliminate. That raises the bar on generation: the two gold answers must themselves be individually right and jointly non-interchangeable, or the question has no real answer.

An item that fails any check is rebuilt with the specific failures fed back into the prompt, up to 4 attempts. In this run, .

The verifier judges four criteria independently — the central test in each is a swap test: if either the interpretation or the response would work about as well paired with the other vocalization, that criterion fails.

What the model is asked

Each pair is rendered as two separate audio files, never mixed into one clip — Dialogue 1 is Turn 1 + one vocalization, Dialogue 2 is the same Turn 1 + the other vocalization. The model is told up front it will hear two distinct dialogues, one at a time. Which of the pair's two versions plays as "Dialogue 1" vs "Dialogue 2" is randomized independently per item, so sound identity is not confounded with listening order. All four questions are asked in one session: identify each sound right after its own audio, then — once both have been heard — match the two gold interpretations and the two gold responses back to the dialogue each actually belongs to.
